# D&D Character Builder

A browser-based tool for creating and playing D&D 5e characters. No build step, no account—just open it and go. Data is saved locally in your browser.

---

## For Players

Use this to **build and run your character** at the table. Create a character with the step-by-step wizard (race, class, background, ability scores, spells, equipment). During play, use the session view to:

- Roll ability checks, saving throws, and skill checks
- Track HP, hit dice, spell slots, and conditions
- Cast spells with descriptions and damage rolls
- Manage inventory and currency
- Level up with XP or milestone mode

Everything stays in your browser, so you can use it offline or host it yourself.

---

## For DMs

Use this to **run your game** and keep things organized. Switch to DM mode to:

- Browse and search monsters by name, CR, or type
- View monster stat blocks and add them to the battle map
- Create and manage NPCs with notes and stats
- Run a grid-based battle map with tokens and terrain
- Save maps for later sessions

You can also add house rules, campaign notes, and custom reference material in the Rules & Reference panel.

---

## Quick Start

Open `index.html` in a browser, or run a local server (e.g. `npx serve`). To host on GitHub Pages, push the project to a repo and enable Pages in Settings → Pages.

See **CONTENT_GUIDE.md** for adding races, classes, spells, and homebrew content.
